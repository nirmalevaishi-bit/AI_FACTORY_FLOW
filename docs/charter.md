### 3. Core Problem Statement

* **What it says:** *In bearing manufacturing factories, production slows down because materials wait too long between machines, queues become overloaded, and managers cannot identify bottlenecks until delays occur*.


* **Explanation:**
* Imagine a factory making **bearings** (the metal rolling parts used in wheels, engines, and machines).
* Even if individual machines are working perfectly fine, production often slows to a crawl because parts pile up in long lines (queues) waiting for their turn at the next machine.
* Some machines get overloaded with too much work while others sit completely empty.
* **The main issue:** Factory managers are usually blind to these problems and only notice a bottleneck *after* a delay has already ruined their schedule.


---

### 4. Proposed Solution

* **What it says:** *An AI system that continuously analyzes production data, predicts waiting times/queue lengths, and recommends optimal machine routing via a Streamlit dashboard*.


* **Explanation:**
* Instead of waiting for delays to happen, your project builds an AI system that acts like an early-warning radar for the factory.


* It reads live factory data (like how long lines are or how busy machines are) and **predicts** how long parts will have to wait.


* If a machine (like a Grinding machine) is getting too crowded, the AI instantly gives a smart recommendation—such as telling the manager to route the next batch of bearings to an alternative machine.


* All of this information is displayed cleanly on an interactive web interface built using **Streamlit** so managers can take action immediately.
